# Glossary

- **Service account:** A 1Password identity for automated access to selected vaults.
- **Service-account token:** The credential authenticating that identity.
- **Vault:** A collection of items stored in 1Password with shared access rules.
- **Secret reference:** An `op://vault/item/field` identifier, not the secret itself.
- **SDK:** A software development kit; here, the official Go library for 1Password.
- **Keychain:** The macOS credential storage service.
- **Developer ID:** An Apple-issued signing identity for software distributed outside the App Store.
- **Hardened runtime:** macOS process protections enabled when signing an executable.
- **Notarization:** Apple's separate check of a signed distribution for malicious software.
- **Homebrew tap:** A Git repository of installation recipes for the Homebrew package manager.
- **Homebrew formula:** The recipe selecting, installing and testing a package.
- **Homebrew bottle:** A prebuilt package installed without compiling from source.
- **Universal binary:** One macOS executable containing both Apple silicon and Intel code.
- **Debian package:** A `.deb` archive with software and metadata for Debian-family systems.
- **apt repository:** Signed package indexes and downloads that support Debian installation and upgrades.
- **Checksum sidecar:** A small file beside an archive containing its SHA-256 digest for integrity verification.
- **GitHub environment:** A named set of deployment secrets and approval rules for Actions jobs.
- **Release candidate:** A specific build being validated before publication.
- **Secret Service:** The Linux desktop protocol for storing credentials through a session service.
- **GNOME Keyring:** A Linux credential-store implementation of Secret Service. Its login keyring is an encrypted collection normally unlocked during desktop login.
- **SSH:** Secure Shell, used to open a terminal session on another machine. SSH login does not necessarily unlock a desktop keyring.
- **Headless:** Running without an interactive desktop session.
- **Environment:** Named string values passed to a program when it starts.
- **exec:** A Unix operation that replaces the current program with another.
- **CLI:** A command-line interface.
- **cgo:** Go's interface to native system libraries, used here for macOS Keychain.
- **D-Bus:** A local messaging system used to communicate with Linux Secret Service.
- **WebAssembly:** A portable executable format used internally by the 1Password SDK.
- **File descriptor:** A process-local handle for an open file, socket, or pipe.
- **Close-on-exec:** A flag that closes an open handle when a process replaces itself.
- **Network namespace:** A separate set of Linux network interfaces and routes, used here to isolate qualification traffic from the host's network configuration.
- **CONNECT proxy:** A forwarding service that carries encrypted TLS connections without decrypting their contents.
- **TLS:** The encryption and certificate-verification protocol used for HTTPS connections.
- **Qualification checkpoint:** A pause added only to an instrumented test build so an observer can inspect a specific process phase reliably.
- **Go overlay:** A build-time mapping that substitutes source files without editing the original checkout files.
